# Safe Sweep — Реверсивный сапёр (Reverse Minesweeper)

> Мины видно с самого начала. Найди все безопасные клетки и не коснись ни одной мины.

**Safe Sweep** — это браузерная игра-головоломка, которая переворачивает классический «Сапёр». В обычном сапёре мины спрятаны, и вы пытаетесь их не задеть. Здесь всё наоборот: мины видны с первого кадра (красные светящиеся бомбы), а ваша задача — открыть все тёмные безопасные клетки. Правило понятно за пару секунд без всякой инструкции: «не трогай красное, открой всё остальное».

Игра создана как тестовое задание для позиции **Product Hacker** в [WaiWai](https://waiwai.is) — микро-хакатон на 90 минут, где нужно собрать маленький работающий продукт с помощью AI.

## Как играть

1. **Откройте страницу.** Сразу видно поле: красные светящиеся клетки — это мины, тёмные клетки — безопасные (пока закрытые).
2. **Левый клик** по тёмной клетке открывает её. Появляется число — сколько мин находится в восьми соседних клетках.
3. **Если число равно нулю**, открывается целый каскад соседних клеток — как в классическом сапёре.
4. **Правый клик** (или долгое нажатие на мобильном) ставит флажок-метку на любую закрытую клетку.
5. **Откройте все безопасные клетки — победа.** Коснётесь мины — проигрыш.
6. **Сразу можно сыграть снова** кнопкой «Play Again» / «Try Again».

### Уровни сложности

| Уровень | Поле | Мины |
|---------|------|------|
| Easy    | 8×8  | 10   |
| Medium  | 12×12| 25   |
| Hard    | 16×16| 50   |

Переключение сложности сразу начинает новую игру. Лучшее время для каждого уровня сохраняется в браузере (localStorage) и показывается над полем.

### Дополнительно

- **Таймер** запускается с первого клика и останавливается на победе или поражении.
- **Звуковые эффекты** генерируются на лету через Web Audio API — без аудиофайлов.
- **Анимации**: открытие клеток, взрыв мины, конфетти при победе.
- **Адаптивный дизайн** — работает на телефоне и на десктопе.

## Технологический стек

Чистый vanilla-стек без единой зависимости и без шага сборки — продукт должен открываться одним кликом и работать даже офлайн после загрузки.

- **HTML5** — разметка страницы (`index.html`)
- **CSS3** — тёмная тема с неоновыми акцентами, CSS Grid для поля, анимации, медиазапросы для адаптивности (`style.css`)
- **JavaScript (ES6+)** — игровой движок, логика, UI-контроллер, звук (`game.js`)
- **Web Audio API** — генерация звуковых эффектов программно (OscillatorNode, GainNode)
- **localStorage** — хранение лучших времён по уровням сложности
- **GitHub Pages** — статический хостинг

Никаких фреймворков, бандлеров, пакетных менеджеров и серверной части. Три файла — и всё работает.

## Три коротких ответа (тестовое задание WaiWai)

### 1. Каким инструментом вы собирали?

Собирал с помощью **Droid от Factory** — автономного AI-агента-разработчика на базе Claude (Anthropic). Я ставил задачу продуктом, а агент самостоятельно исследовал требования, писал код (HTML, CSS, JS), проверял механику в браузере через автоматизацию и деплоил результат на GitHub Pages. Параллельно использовал `gh` CLI для создания репозитория и включения GitHub Pages.

### 2. На какой минуте записи AI ошибся заметнее всего и что вы сделали?

Примерно на **12-й минуте** AI сначала сгенерировал поле как в классическом сапёре: мины были **спрятаны**, а по первому клику гарантировалась безопасная клетка. Это ломало главную идею «игры наоборот» — мины должны быть видны с самого начала. Заметил сразу при первом рендере: красных светящихся бомб не было, клетки выглядели как обычный сапёр. Сказал об этом вслух, попросил AI сделать мины видимыми с первого кадра (красные клетки с иконкой бомбы и свечением) и убрать логику «первый клик безопасен». После правки правило стало считываться за секунды — ровно как требует задание.

### 3. Что бы вы сделали с продуктом завтра, если бы продолжали?

Добавил **таблицу рекордов с именами** (сейчас лучшие времена хранятся только локально), **ежедневный челлендж** — одно и то же поле для всех в этот день, чтобы появился повод возвращаться, и **кастомные уровни** с настройкой размера и количества мин. Из более крупного — **мультиплеер на скорость**: кто быстрее очистит своё поле, и обёртка в PWA, чтобы игра устанавливалась на телефон и работала офлайн.
